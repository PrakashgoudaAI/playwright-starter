# Security policy

Do not include exploit details or sensitive information in a public issue. Use GitHub's **Report a vulnerability** option when available. If it is unavailable, open an issue asking the maintainer to arrange a private reporting channel, without sharing the vulnerability itself.

Never commit credentials, storage state, reports containing sensitive data, or test artifacts from non-synthetic systems.

The bundled application is a localhost-only test target, not a supported authentication service. Its accounts are intentionally public. See the README for its limitations before reusing any code.
